# Sealed Bid Vault

BidVault sería una plataforma de ofertas selladas para procesos de M&A o subastas privadas. Cada participante envía una oferta cifrada que nadie puede leer hasta el cierre del proceso; además, cada oferta va firmada digitalmente para verificar quién la envió y detectar cualquier modificación. Así podemos integrar autenticación, cifrado, integridad, firma digital y gestión segura de claves de forma bastante natural.
